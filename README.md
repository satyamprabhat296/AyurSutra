# 🌿 AyurSutra

### Panchakarma Patient & Clinic Management System

AyurSutra is a full-stack healthcare management system designed specifically for Ayurvedic and Panchakarma clinics.

It helps clinics manage patients, doctors, appointments, consultations, prescriptions, medicines, inventory, purchases, billing, and reports from a centralized platform.

---

## 🚀 Features

### 🔐 Authentication & Authorization

- JWT-based authentication
- Secure cookie-based login
- Role-based access control
- Multiple staff roles
- Protected API routes

### 👤 Patient Management

- Patient registration
- Patient profiles
- Patient ID generation
- Patient contact information
- Patient history
- Clinic-based patient isolation

### 👨‍⚕️ Staff Management

Supports multiple staff roles:

- Super Admin
- Doctor
- Receptionist
- Therapist
- Pharmacist
- Accountant

Staff management includes:

- Staff registration
- Qualification
- Specialization
- Experience
- Consultation fee
- Availability

### 📅 Appointment Management

- Appointment booking
- Appointment numbers
- Token numbers
- Doctor assignment
- Visit type
- Appointment status tracking
- Follow-up dates
- Appointment notes
